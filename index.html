About

The panels are plain HTML <aside> elements. A single script handles opening and closing them.

Flyout anatomy

Any element with data-flyout-target="id" opens the panel with that id.

Markup
<aside class="flyout" id="x" data-side="right">
Sides: left, right, bottom. Add data-modal="false" to drop the backdrop.
Keyboard
Esc closes the top panel. Tab stays inside modal panels. Focus goes back to the button that opened the panel.
JavaScript API
Flyout.open(id), Flyout.close(id), Flyout.toggle(id), Flyout.closeAll(). Each panel fires flyout:open and flyout:close events.
Stacking
Panels on different sides can be open together. Try opening the bottom sheet from here.

Publish to GitHub Pages

  1. Push this repository to GitHub.
  2. Open Settings → Pages.
  3. Under Build and deployment, choose Deploy from a branch.
  4. Pick branch main and folder / (root), then save.
  5. After a minute or so the site is live at https://<user>.github.io/<repo>/.
